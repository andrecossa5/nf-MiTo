# Pre-processing tutorial

nf-MiTo 2.0.0 turns the raw data of one library (FASTQ files, or a BAM of the MT reads) into the single-cell tables read by `mt.io.make_afm()`. This tutorial runs the pipeline on the small test sets of the tools it packages: an mtscATAC BAM (mgatk) and a ReDeeM FASTQ library (RedeemV). MAESTER follows the same steps (see [MAESTER](#maester)).

## Prerequisites

- [Nextflow](https://www.nextflow.io/) ≥ 24.04.0 and one of Docker, Singularity/Apptainer or Conda (`-profile docker|singularity|conda`).
- `mtscATAC` and `ReDeeM` align reads with bwa-mem2 (x86_64 only). Building its index for a human genome needs about 80 GB of memory, once.
- A **NUMT-masked genome FASTA** (uncompressed) with the MT contig, given with `--masked_ref`. nf-MiTo does not download or mask a genome. In the examples it is `masked.fa`.

## The samplesheet

One library per run, one row:

```csv
sample,fastq_dir,bam,cell_barcodes
donorX,/data/donorX_fastq,,/data/donorX_cells.txt     # FASTQ input
donorX,,/data/donorX_MT.bam,/data/donorX_cells.txt    # BAM input
```

Give either `fastq_dir` or `bam`. `cell_barcodes` is required: one barcode per line, as found in the BAM tag (`--barcode_tag`, default `CB`). The tables are copied directly into `--output_folder`, so use one output folder per library (e.g. `results/donorX`).

## Example 1: mtscATAC from a BAM (mgatk)

Download the test BAM bundled with mgatk (37 cells, 50,000 MT reads, 2.7 MB), which also writes the samplesheet:

```bash
bash params/download_mgatk_test_data.sh mgatk_test_data
```

Parameters (`params.json`):

```json
{
  "assay": "mtscATAC",
  "input": "mgatk_test_data/samplesheet.csv",
  "output_folder": "results/cra_v2",
  "string_MT": "chrM",
  "barcode_tag": "CB",
  "masked_ref": "masked.fa"
}
```

Run:

```bash
nextflow run andrecossa5/nf-MiTo -r v2.0.0 -profile singularity -params-file params.json
```

With a BAM as input, the reads are not aligned: the BAM is split in one pass into batches of cells (`--batch_size`), mgatk (`bcall` mode) counts the cells of each batch one at a time, and the batches are collapsed into the tables.

Output (`results/cra_v2`):

```
A.txt.gz  C.txt.gz  G.txt.gz  T.txt.gz  coverage.txt.gz  depth.txt.gz  refAllele.txt
resources/
```

## Example 2: ReDeeM from FASTQ (RedeemV)

Download the example library of RedeemV (250,000 read triplets, 10x Multiome ATAC enriched for chrM, and the Cell Ranger ARC cell list), which also writes the samplesheet:

```bash
bash params/download_redeemv_test_data.sh redeemv_test_data
```

The cell list is in the RNA barcode space (Cell Ranger ARC), so we set `--barcode_space RNA`. The barcodes are translated to the ATAC space through the 10x Multiome whitelist pair.

```json
{
  "assay": "ReDeeM",
  "input": "redeemv_test_data/samplesheet.csv",
  "output_folder": "results/quickstart",
  "string_MT": "chrM",
  "barcode_space": "RNA",
  "masked_ref": "masked.fa"
}
```

The pipeline then: concatenates lanes, reads the ATAC barcode from the barcode read (`--atac_barcode_rule auto`), aligns the reads with bwa-mem2 to the masked genome, keeps the MT pairs (`--atac_min_mapq`), splits the BAM into batches of cells, calls molecule consensus genotypes cell by cell (`--redeem_base_quality`) and finally removes strand-biased variants over the whole library (`--redeem_strand_bias_*`).

Output (`results/quickstart`):

```
RawGenotypes.Total.StrandBalance.gz  RawGenotypes.VerySensitive.StrandBalance.gz
RawGenotypes.Sensitive.StrandBalance.gz  RawGenotypes.Specific.StrandBalance.gz
QualifiedTotalCts.gz  StrandBiasBlackList  StrandBiasTable.tsv.gz
resources/
```

## MAESTER

MAESTER reads are aligned with STARsolo (barcode 1-16, UMI 17-28), so a STAR index is needed: it is built once from `--masked_ref` and the GENCODE annotation (`--gtf`), or taken from `--prebuilt_STAR_index` with `--build_STAR_index false` (see [`create_STAR_index.md`](create_STAR_index.md)). `fastq_dir` holds `*R1*.fastq.gz` and `*R2*.fastq.gz`; `cell_barcodes` lists the barcodes of the cells to analyse (e.g. the cells called on the GEX data).

```json
{
  "assay": "MAESTER",
  "input": "samplesheet.csv",
  "output_folder": "results/donorX",
  "masked_ref": "masked.fa",
  "build_STAR_index": true
}
```

Per cell, maegatk filters the reads (`--maegatk_NHmax`, `--maegatk_NMmax`), builds UMI consensus reads with fgbio (`--maegatk_min_reads`), re-maps them and counts the alleles (`--maegatk_base_qual`, `--maegatk_alignment_quality`). The output is `A.txt.gz`, `C.txt.gz`, `G.txt.gz`, `T.txt.gz`, `coverage.txt.gz` and `depth.txt.gz`.

## Running on a cluster

Site settings (executor, queues, pre-installed conda environments) go in a `-c user.config` file, see [`config/user.config`](../config/user.config):

```bash
nextflow run <path to nf-MiTo>/main.nf -params-file params.json -profile slurm,conda -c user.config
```

`--batch_size` (default `auto`: about 75 tasks per library, 100 to 1000 cells each) only sets how many tasks the library is divided into; the memory of a task is that of a single cell.

## Load the tables in MiTo

```python
import mito as mt
afm = mt.io.make_afm('results/quickstart', 'ReDeeM', 'redeem-v')    # ('MAESTER', 'maegatk'), ('mtscATAC', 'mgatk')
```

Parameters of every group are listed in the [README](../README.md#parameters).
